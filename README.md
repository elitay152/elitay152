# Hi, I'm Eli 👋

**Data engineer and former registered nurse** building reliable pipelines for healthcare data.

I spent 8+ years in nursing before moving into data, so I know what happens when clinical data is late, incomplete, or wrong. Most recently I built ETL pipelines, dbt models, and Snowflake cost monitoring at a digital health startup, and before that I automated quality-reporting pipelines in Databricks for a Medicaid health plan serving ~600,000 members.

**Stack:** Python · SQL · Snowflake · Databricks · PySpark · dbt · PostgreSQL · Dagster · AWS · Azure · Docker · Kubernetes · GitHub Actions

## Featured projects

- **[Careflow](https://github.com/elitay152/Careflow)**: healthcare data platform. Ingests FHIR records into PostgreSQL, models them with dbt (13 models, 49 data quality checks), and orchestrates with Dagster. [Live dashboard →](https://elitay152.github.io/careflow-dashboard/)
- **[health-atlas](https://github.com/elitay152/health-atlas)**: county health explorer for Oregon and Washington, built on CDC PLACES data with DuckDB and Streamlit.
- **[clinical-llm-extraction](https://github.com/elitay152/clinical-llm-extraction)**: extracts medications, doses, routes, and frequencies from clinical notes, comparing a token classifier with prompted and fine-tuned LLMs.
